# Umless Keyboard 0.1.4

## Fixed

- The keyboard theme was reset to the default after updating: custom image themes and themes picked from the list are now kept across updates.
- If a custom theme can't be read right after an update or a reboot, your choice is no longer overwritten; the keyboard switches back to your theme the next time it opens.

## Note

- If your theme was reset before, settings such as "Follow system day/night" may also have been reset — please check your keyboard settings.
