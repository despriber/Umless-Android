# Umless 输入法 0.1.2

首个公开测试版（仅 arm64 手机）。

## 新增

- 完整的中文输入法（基于 fcitx5 的拼音键盘），新增 Umless 浅色 / 深色主题。
- 长按空格说话：松开后自动去口癖、纠错、排版并写入光标处；上滑取消，写入后可一键换回原话或撤销。
- 工具栏麦克风打开语音面板，按住大按钮说话。
- 主 App 与桌面端同一套界面：概览、报告（每日诊断与习惯卡）、练习、历史、设置与新手引导；评分规则与桌面端完全一致。
- 隐私：密码框不能使用语音；无痕输入框、黑名单应用、暂停记录时说的话不留任何记录；导出诊断日志不含原文和 API Key。
- 应用内检查更新：发现新版本时提示，下载后校验文件与签名再安装，数据保留。

## 改进与修复

- 不配置大模型时，英文也会自动改成正常大小写。
- 新手引导改为先下载识别模型再测试麦克风，测试时就能看到识别出的文字。
- 「切换为 Umless 键盘」弹不出选择框时，自动打开系统输入法设置并提示在哪里选择。
- 冷启动后第一次说话可能录到 0 秒；开始震动改为麦克风真正开始录音之后，开头不再丢字。
- 识别模型只在最近用过语音时常驻内存，减少对其他 App 的影响。
- 可以从 0.1.0 / 0.1.1 测试包直接覆盖安装。
