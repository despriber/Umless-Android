# Umless Keyboard 0.1.2

The first public test release (arm64 phones only).

## New

- A complete Chinese input method (fcitx5 pinyin keyboard) with new Umless light and dark themes.
- Long-press space to talk: release and Umless removes fillers, fixes errors, formats and inserts at the cursor; slide up to cancel, and switch back to your original words or undo with one tap.
- The toolbar mic opens a voice panel with a big hold-to-talk button.
- The same main app as the desktop: Overview, Reports (daily diagnosis and habit cards), Practice, History, Settings and onboarding — with exactly the same scoring rules.
- Privacy: voice never works in password fields; nothing is kept from incognito fields, excluded apps or while history is paused; exported diagnostic logs contain neither transcripts nor API keys.
- In-app update checks: new versions are announced, then downloaded and verified (file and signature) before installing; your data is kept.

## Improved and fixed

- Without an LLM, English now gets normal casing.
- Onboarding downloads the speech model before the microphone test, so the test shows the transcript.
- If "Switch to the Umless keyboard" can't open the picker, system keyboard settings open with a hint where to choose.
- The first dictation after a cold start could record 0 seconds; the start vibration now comes once the mic is really recording, so the beginning isn't lost.
- The speech model stays in memory only if you used voice recently, easing pressure on other apps.
- Installs directly over the 0.1.0 / 0.1.1 test builds.
