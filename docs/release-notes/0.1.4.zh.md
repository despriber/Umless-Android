# Umless 输入法 0.1.4

## 修复

- 升级后键盘主题被重置为默认主题：自定义图片主题、主题列表里选的主题，升级后都会保留。
- 升级或开机后自定义主题一时读不出来时，不再改掉你的选择；之后弹出键盘时会自动换回你的主题。

## 提示

- 如果你之前遇到过主题被重置，「跟随系统深浅色」等键盘设置可能也被改回了默认值，建议到键盘设置里检查一下。
